# The MCC Tower

The Millennium Challenge Corporation model as a Jenga tower: what the blocks are, who prizes which, and what happens when you pull one or pile more on.

- `index.html`: reference view (20 blocks, audience matrix, leverage chart)
- `play.html`: build-your-own version, with risk tolerance and stress tests
- `data.js`: every block and every score. Edit here to change the assumptions.
- `model.js`: the scoring rules
- `mcc-tower-thought-piece.pdf`: the accompanying note

No build step. All audience, leverage, weight and strain scores are the author's judgment, not polled positions.
